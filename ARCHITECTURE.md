# QARAQU FACE — архитектурная схема

Система видеонаблюдения с детекцией и распознаванием лиц. Пайплайн камер близок к модели [FindFace Multi 2.4.1](https://docs.ntechlab.com/projects/ffmulti/en/2.4.1/architecture.html#architecture-scheme): один декодер на поток, буфер кадра в ОЗУ, детекция по движению, лучший кроп в 1:N, основной поток — только когда нужен.

---

## 2. Компоненты

| Слой | Модуль | Назначение |
|------|--------|------------|
| API / UI | `api.py`, `web/templates/console.html` | Консоль, REST, MJPEG, админка |
| Оркестрация | `runtime.py` | Воркеры камер, опции, галерея, события |

| Данные | `db.py`, `cameras_store.py` | SQLite, камеры, sightings, настройки |

## 3. Поток данных по камере (как у FindFace)

### 3.1. Декодирование

- Один RTSP-поток на воркер детекции (по умолчанию **sub**).
- Декод на **GPU (NVDEC)** через PyAV CUDA; CPU не разбирает H.264.
- В ОЗУ — **один** BGR-кадр (слот) и серая миниатюра 96×72 для движения.
- Частота слота: ~4 кадр/с при движении, ~1 кадр/с в тишине.
- Если sub слишком мелкий (CIF &lt; 480 px по стороне) — автоматический переход на **main**.

### 3.2. Детекция по движению

| Состояние сцены | Когда гоняется YOLO |
|-----------------|----------------------|
| Движение выше порога | сразу на новом кадре |
| Есть активный трек | ~каждые 2 с |
| Пустая неподвижная сцена | ~каждые 5 с (keepalive) |
| Открытое превью | чаще, на новых кадрах |

Инференс сериализован: один семафор + общий GPU-замок TensorRT (YOLO / YuNet / ArcFace не параллелятся — иначе SIGSEGV).

### 3.3. Основной поток (main)

- Открывается **только** при движении или в первые секунды трека.
- Нужен для мелких лиц на sub и доуточнения 1:N.
- Одновременно не больше **одного** main NVDEC на весь сервис.
- Если детекция уже на main — второй декодер не открывается.
- Превью стены берёт кадр из того же слота детекции (второй RTSP на стену не дублируется).

### 3.4. Распознавание

```text
кроп лица
   │
   ├─ фильтры: YuNet ≥ 0.5, резкость, доля кожи (отсев блика/монитора)
   │
   ▼
ArcFace (embeddings.npy) ── совпало? ──► known
   │ нет
   ▼
AdaFace (embeddings_ada.npy), если галерея не пуста
   │ нет
   ▼
Unknown #N / near-name
```

- Порог ArcFace и AdaFace раздельные.
- Векторы моделей **не усредняются** между собой.
- На «лучшем» кропе интервала (~0.9 с), не на каждом боксе.
- Известный человек в тишине: рамка держится, полный 1:N не крутится каждые кадр; YuNet/блик всё равно перепроверяются.

## 5. Хранение

```text
data/
├── gallery/<человек>/
│   ├── source.jpg
│   ├── embeddings.npy      ← ArcFace
│   └── embeddings_ada.npy  ← AdaFace (если есть)
├── snapshots/              ← кропы проходов
├── models/*.engine         ← TensorRT CC 12.0
└── qaraqu_face.db          ← камеры, sightings, опции, пользователи
```

Картотека — **файлы**, не строки в SQL. Список людей строится по наличию векторов Arc и/или Ada.

## 6. Управление нагрузкой

| Рычаг | Эффект |
|-------|--------|
| Motion gate | пустые комнаты почти не грузят GPU |
| Слот 1–4 fps | меньше `to_ndarray` / копий в ОЗУ |
| GPU lock | стабильность TensorRT |
| 1× main NVDEC | нет шторма вторых 1080p-потоков |
| CIF → main | качество детекции без вечного reopen refine |
| Фильтр блика (кожа / YuNet / резкость) | мониторы и лампы не становятся «человеком» |
| Выключение сервиса | NVDEC-сессии закрываются, а не висят в фоне |

Консольный «% GPU» — заполнение **VRAM**, не утилизация SM. Реальную загрузку смотреть в `nvidia-smi`.

## 7. Соответствие FindFace Multi (упрощённо)

| FindFace Multi | QARAQU FACE |
|----------------|-------------|
| video-manager / jobs | `Runtime` + `detect_on` |
| video-worker-gpu | `CameraWorker` + `gpu_capture` (NVDEC) |
| imotion_threshold | motion по миниатюре слота |
| best shot → facerouter | лучший кроп → ArcFace/AdaFace |
| realtime_post_interval | `_EMBED_EVERY_S` |
| отдельный streamer превью | JPEG/MJPEG из того же слота |
| RAM на камеру | один BGR-слот + thumb |

## 8. Точки входа

| Действие | Как |
|----------|-----|
| Старт сервиса | `cd /data/nimda/qaraqu_face && …/python run.py` → `:5020` |
| Включить потоки | `POST /api/admin/streams/start` |
| Остановить потоки | `POST /api/admin/streams/stop` |
| Консоль | `/` (логин из настроек / `config/default.yaml`) |

После рестарта детекция по умолчанию **выключена**, пока не включить потоки (или `QARAQU_FACE_ENABLED=1`).
