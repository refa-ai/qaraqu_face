# Основной принцип qaraqu_face

**Этот документ — якорь проекта.** Любые фичи, эксперименты с моделями и рефакторинг должны служить ему, а не уводить в сторону.

## Что это за программа

Программа для **распознавания и определения лиц** и **трекинга движения объектов** по камерам в офисе.

## Суть

1. В офисе стоят **камеры**.
2. Система **находит лица/объекты** в кадре.
3. Сверяет их с **картотекой** (известные люди).
4. Строит **карту движения**: куда какой объект двигается (траектории, переходы между зонами/камерами).
5. Объекты, которых **нет в картотеке**, тоже отслеживаются — отдельный трекинг «неизвестных» по движению.

## Два потока объектов

| Тип | Источник ID | Что делаем |
|-----|-------------|------------|
| **Известный** | Совпадение с картотекой (face ID / имя) | Распознать → вести трек → писать маршрут на карте движения |
| **Неизвестный** | Нет в картотеке | Не отбрасывать: присвоить временный track-id → вести по движению → тоже на карте (отдельно от известных) |

## Главный результат

Не «красивый детект ради детекта», а **оперативная картина офиса**:

- кто (или «неизвестный #N») где был;
- куда движется;
- история перемещений по времени и камерам.

## Что вторично

Эксперименты с детекторами (YOLO, UltraFace, …), liveness, генерацией лиц, 3D и т.п. — **инструменты**. Они допустимы только если помогают лучше:

- находить лица,
- стабильно трекать,
- матчить с картотекой,
- строить карту движения известных и неизвестных.

Если идея не усиливает эти четыре пункта — она вне приоритета.
